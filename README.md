# Agente de Processos (SOP) & Operações (`skill-operacoes-ai-cowork`)

> Skill oficial distribuída pela **AI Cowork Academy** para empresários e gestores estruturarem **Operações & Gestão** com Agentes de IA.

## O que este agente faz

Transforma tarefas repetitivas da empresa em processos padronizados (SOPs) com responsável, passo a passo e checklist de qualidade.

## Como instalar em 1 comando

Copie e cole este prompt direto na sua IA (Claude Code, Codex, ChatGPT ou Antigravity):

```text
Acesse o repositório https://github.com/nitroxinteligence/skill-operacoes-ai-cowork, leia o arquivo SKILL.md completo (e a pasta references/) e instale esta skill no meu workspace para eu usar agora.
```

## Como utilizar na prática

Descreva em texto solto (ou áudio transcrito) como uma rotina é feita hoje na sua empresa. O agente organiza em um manual passo a passo pronto para delegar ao time.
